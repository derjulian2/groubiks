
# NeoGroubiks

A rubiks-cube simulator that was sparked from the idea of
applying group-theory on rubiks-cubes.

# Dependencies and Credits

* [SFML](https://www.sfml-dev.org/)
* [Dear-ImGui](https://github.com/ocornut/imgui)
* [SFML-backend](https://github.com/SFML/imgui-sfml)
